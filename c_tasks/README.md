# Завдання 11–20 на C

Усі завдання реалізовані на стандартному C11. Кожне завдання — окремий
підкаталог із вихідним файлом, при потребі — приклад вхідних даних.

## Швидкий старт

```bash
cd c_tasks
```

попереджень.

## Завдання 11. Анаграми зі списку слів у `.txt` файлі

`task_11_anagrams/anagrams.c`

**Постановка.** Прочитати слова з текстового файлу та згрупувати анаграми
(слова з однаковим набором літер). Кожну групу вивести в окремому рядку.

**Ідея.** Для кожного слова обчислюємо "ключ" — це саме слово з посортованими
літерами. У всіх анаграм ключ один і той самий. Сортуємо масив пар
`(ключ, оригінал)` за ключем, після чого послідовні елементи з однаковим
ключем утворюють групу анаграм.

**Часова складність.**
`O(N · L · (log L + log N))`, де `N` — кількість слів, `L` — середня
довжина:
- `O(L log L)` на побудову ключа для кожного слова;
- `O(N log N)` порівнянь у `qsort`, кожне порівняння рядків — `O(L)`.

**Просторова складність.** `O(N · L)` — копії слів і ключів.

**Запуск.**
```bash
./task_11_anagrams/anagrams task_11_anagrams/words.txt
```

Вхід: `eat tea tan ate nat bat cat act tac listen silent enlist hello world`

Вихід (групи на окремих рядках):
```
bat
cat act tac
eat tea ate
tan nat
world
hello
listen silent enlist
```

## Завдання 12. Найкоротший шлях у неорієнтованому графі (BFS)

`task_12_bfs/bfs.c`

**Постановка.** Дано неорієнтований граф, список початкових вершин і
кінцева вершина. Повернути найкоротший шлях від будь-якої з початкових
вершин до кінцевої.

**Ідея.** Багатоджерельний BFS: усі стартові вершини одразу кладемо в
чергу з відстанню 0. BFS у незваженому графі гарантує, що при першому
відвіданні вершини шлях до неї є найкоротшим. Масив `parent[]` дозволяє
відновити сам шлях.

**Часова складність.** `O(V + E)`.

**Просторова складність.** `O(V + E)` — список суміжності, черга, масиви
`visited` і `parent`.

**Запуск.**
```bash
./task_12_bfs/bfs
```
У `main()` визначено приклад графу та джерел `{0, 2}`, ціль `5`. Вихід:
```
Найкоротший шлях (вершин: 3): 2 -> 4 -> 5
```

## Завдання 13. Будь-який шлях у неорієнтованому графі (DFS)

`task_13_dfs/dfs.c`

**Постановка.** Аналогічно завданню 12, але достатньо повернути
будь-який шлях (не обов’язково найкоротший).

**Ідея.** Рекурсивний DFS зі стартом по черзі з кожної з джерельних
вершин. Виходимо одразу, як тільки досягли цільової. Шлях відновлюємо
через `parent[]`.

**Часова складність.** `O(V + E)`.

**Просторова складність.** `O(V)` для `visited`/`parent` плюс `O(V)` на
стек рекурсії; список суміжності — `O(V + E)`.

**Запуск.**
```bash
./task_13_dfs/dfs
```
Приклад виводу:
```
DFS шлях (вершин: 4): 0 -> 1 -> 3 -> 5
```

## Завдання 14. Тип `EmailAddress` із методом `compareTo()`

`task_14_email/email.c`

**Постановка.** Створити тип, який зберігає електронну адресу, і
впорядкувати список адрес спочатку за доменом, потім за ім’ям
користувача.

**Ідея.** У C немає класів, тому використовуємо `struct EmailAddress` із
полями `username`, `domain`, `original`. Аналог `compareTo()` —
функція `email_compare(a, b)`, яка викликає `strcmp` спочатку для
доменів, а при рівності — для імен користувачів. Її можна напряму
передати у `qsort()`.

Клієнтська програма зчитує адреси з `stdin` (по одній на рядок), парсить
їх по символу `@`, сортує і записує у файл, переданий аргументом
командного рядка.

**Часова складність.** `O(N · log N · L)`, де `L` — середня довжина
адреси (порівняння рядків коштує `O(L)`).

**Просторова складність.** `O(N · L)`.

**Запуск.**
```bash
printf "bob@example.com\nalice@example.com\ncarol@aaa.com\nzed@example.com\n" \
  | ./task_14_email/email task_14_email/out.txt
cat task_14_email/out.txt
```
Вихід:
```
carol@aaa.com
alice@example.com
bob@example.com
zed@example.com
```

## Завдання 15. Перевірка перестановки рядків

`task_15_permutation/permutation.c`

**Постановка.** Прочитати з файлу два рядки. Повернути `true`, якщо один
рядок є перестановкою символів іншого.

**Ідея.** Два рядки — перестановки одне одного тоді й лише тоді, коли
у них однакові мультимножини байтів. Заводимо масив `counts[256]`,
збільшуємо лічильники для першого рядка, зменшуємо для другого. Якщо у
підсумку всі лічильники нульові — це перестановка. Швидке відсікання:
якщо довжини різні, відразу `false`.

**Часова складність.** `O(L1 + L2)`.

**Просторова складність.** `O(1)` — фіксований масив на 256 елементів.

**Запуск.**
```bash
./task_15_permutation/permutation task_15_permutation/strings.txt
```
Файл містить:
```
listen
silent
```
Вихід: `true`.

## Завдання 16. Об’єднання масивів без дублікатів

`task_16_merge/merge.c`

**Постановка.** Прийняти два масиви, об’єднати в один, видалити дублікати,
повернути відсортований масив унікальних елементів.

**Ідея.** Найпрямолінійніший підхід:
1. Скопіювати обидва масиви в один спільний.
2. Посортувати його `qsort()`-ом.
3. Пройти лінійно й залишити лише ті елементи, що відрізняються від
   попереднього (стиснення дублікатів in-place).

**Часова складність.** `O((N1 + N2) · log(N1 + N2))` — сортування домінує.

**Просторова складність.** `O(N1 + N2)` — об’єднаний буфер.

**Запуск.**
```bash
./task_16_merge/merge
```
Вихід:
```
Унікальний відсортований масив: 1 2 3 4 5 6 7 8 9
```

## Завдання 17. Знаходження циклу в орієнтованому графі

`task_17_cycle/cycle.c`

**Постановка.** Дано орієнтований незважений граф. Визначити, чи містить
він цикл, і якщо так — вивести будь-який із них.

**Ідея.** DFS із трьома кольорами:
- `WHITE` — не відвідано;
- `GRAY` — у поточному стеку рекурсії;
- `BLACK` — повністю опрацьовано.

Якщо під час обходу зустрічаємо ребро `u → v`, де `v` уже `GRAY`, то `v`
лежить на поточному шляху від кореня DFS до `u`, тобто `v ⇒ ... ⇒ u → v`
утворює цикл. Запам’ятовуємо пару `(v, u)` і відновлюємо цикл,
піднімаючись від `u` по `parent[]` до `v`.

**Часова складність.** `O(V + E)`.

**Просторова складність.** `O(V)` для `color`/`parent` плюс список
суміжності `O(V + E)`.

**Запуск.**
```bash
./task_17_cycle/cycle
```
У `main()` тестовий граф з циклом `1 → 2 → 3 → 1`. Вихід:
```
Цикл знайдено: 1 -> 2 -> 3 -> 1
```

## Завдання 18. Валідне BST

`task_18_bst_valid/bst_valid.c`

**Постановка.** Перевірити, чи є бінарне дерево коректним бінарним
деревом пошуку (BST).

**Ідея.** Локальної умови `left.value < node.value < right.value`
недостатньо — треба гарантувати, що УСІ значення лівого піддерева менші
за корінь і УСІ значення правого піддерева більші. Тому рекурсивно
проносимо допустимий діапазон `(min_excl, max_excl)`. Корінь повинен
суворо в нього потрапити; для лівого піддерева верхня межа стає
`node.value`, для правого — нижня. Початковий діапазон —
`(LLONG_MIN, LLONG_MAX)`.

**Часова складність.** `O(N)` — кожна вершина відвідується раз.

**Просторова складність.** `O(H)` — глибина рекурсії, де `H` — висота
дерева; у найгіршому випадку `O(N)`.

**Запуск.**
```bash
./task_18_bst_valid/bst_valid
```
Вихід:
```
Дерево 1: коректний BST
Дерево 2: не BST
```

## Завдання 19. Збалансованість BST

`task_19_bst_balanced/bst_balanced.c`

**Постановка.** Перевірити, чи є бінарне дерево пошуку збалансованим за
висотою (для кожної вершини `|h(left) − h(right)| ≤ 1`).

**Ідея.** Наївна реалізація обчислює висоту окремо для кожної вершини —
`O(N²)`. Ефективна модифікація: під час однопрохідного обчислення висоти
повертаємо `-1` як сигнал «уже знайдено дисбаланс», що відразу зупиняє
подальші обчислення.

**Часова складність.** `O(N)`.

**Просторова складність.** `O(H)` — глибина рекурсії.

**Запуск.**
```bash
./task_19_bst_balanced/bst_balanced
```
Вихід:
```
Дерево 1: збалансоване
Дерево 2: незбалансоване
```

## Завдання 20. Сортування символів за частотою

`task_20_freq_sort/freq_sort.c`

**Постановка.** Прийняти масив символів і повернути їх, посортованих за
частотою появи (від більшої до меншої). При рівних частотах — зберегти
початковий порядок (стабільне сортування).

**Ідея.**
1. Підрахувати частоти у `counts[256]`.
2. Створити масив записів `Item{ ch, freq, orig_idx }`.
3. Посортувати компаратором, який спершу порівнює `freq` за спаданням,
   а при рівній частоті — `orig_idx` за зростанням. Це робить
   результат стабільним незалежно від того, чи `qsort` стабільна.
4. Переписати вхідний масив.

**Часова складність.** `O(N · log N)`.

**Просторова складність.** `O(N)`.

**Запуск.**
```bash
./task_20_freq_sort/freq_sort
```
Вихід:
```
"tree"  -> "eetr"
"aabbc" -> "aabbc"
"Aabb"  -> "bbAa"
"cccaaabb" -> "cccaaabb"
```
